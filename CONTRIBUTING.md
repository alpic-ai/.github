# Contributing to Alpic open source

Thanks for your interest in contributing. Alpic builds MCP infrastructure and open-source tooling (notably [Skybridge](https://github.com/alpic-ai/skybridge)). We prefer small, well-scoped contributions tied to a clear problem.

## Prefer the product repository

Open issues and pull requests on the **specific repository** you want to change, not on this `.github` meta-repo (unless you are improving org defaults or the profile README).

Examples:

| Area | Repository |
| --- | --- |
| Skybridge framework / CLI / docs site content issues that belong in-repo | [alpic-ai/skybridge](https://github.com/alpic-ai/skybridge) |
| ChatGPT App starter | [alpic-ai/apps-sdk-template](https://github.com/alpic-ai/apps-sdk-template) |
| WebMCP | [alpic-ai/webmcp](https://github.com/alpic-ai/webmcp), [alpic-ai/webmcp-proxy](https://github.com/alpic-ai/webmcp-proxy) |
| Testing / eval / conformance | [grizzly](https://github.com/alpic-ai/grizzly), [mcp-eval](https://github.com/alpic-ai/mcp-eval), [mcp-app-conformance](https://github.com/alpic-ai/mcp-app-conformance) |
| Org profile & default community health | [alpic-ai/.github](https://github.com/alpic-ai/.github) (this repo) |

If a repository has its own `CONTRIBUTING.md`, follow that document.

## Before you start

1. Search existing issues and PRs on the target repo
2. For non-trivial changes, open an issue first so we can align on approach
3. Keep security reports private (see [SECURITY.md](./SECURITY.md))

## Pull requests

- Fork the repo (or use a branch if you have write access)
- Keep PRs focused: one concern per PR when practical
- Describe **what** changed and **why**
- Include reproduction steps or screenshots when relevant
- Follow the repository's existing code style, lint, and test commands
- Do not commit secrets, credentials, or private customer data

## Code of conduct

Participation is governed by our [Code of Conduct](./CODE_OF_CONDUCT.md).
