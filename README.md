# alpic-ai/.github

Default community health files and the public [organization profile](https://github.com/alpic-ai) for [Alpic](https://alpic.ai).

## What lives here

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](./profile/README.md) | Org landing page shown on github.com/alpic-ai |
| [`profile/assets/`](./profile/assets/) | Profile banner and related assets |
| [`SECURITY.md`](./SECURITY.md) | Default security policy for Alpic repositories |
| [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) | Contributor Covenant code of conduct |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | How to contribute across the org |
| [`SUPPORT.md`](./SUPPORT.md) | Where to get help |
| [`.github/ISSUE_TEMPLATE/`](./.github/ISSUE_TEMPLATE/) | Default issue templates |
| [`.github/pull_request_template.md`](./.github/pull_request_template.md) | Default pull request template |

Repositories that define their own community health files keep those; everything else inherits from this repo.
