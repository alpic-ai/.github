### Hi, we're Alpic

**Alpic** is the cloud platform for [MCP](https://modelcontextprotocol.io)-based AI apps. Build with open-source tools, deploy to production, observe how assistants use your product, and scale.

Based in Paris. Building infrastructure for the agent era.

## Learn

- **Platform** · [alpic.ai](https://alpic.ai): deploy, monitor, and distribute MCP servers and ChatGPT / Claude apps
- **Docs** · [skybridge.tech](https://skybridge.tech): build type-safe MCP Apps with Skybridge
- **Flagship OSS** · [Skybridge](https://github.com/alpic-ai/skybridge) (v2): full-stack TypeScript framework for MCP Apps and ChatGPT Apps. React-powered, platform-agnostic

```bash
npm create skybridge@latest my-app
```
